# FinOps

## Overview

This project is a hands-on Linux laboratory created as part of my FinOps and Cloud learning journey.

The goal is to develop practical Linux skills that help me understand Cloud infrastructure, resource utilization, troubleshooting, and eventually Cloud cost optimization.

## Objectives

- Understand Linux fundamentals
- Manage users and permissions
- Understand processes and services
- Explore Linux networking
- Practice troubleshooting
- Monitor system resources
- Use Git and GitHub for documentation 
- Connect infrastructure concepts with FinOps principles

## Technologies

- Ubuntu Linux
- Bash
- Git
- GitHub
- Nginx

## Learning path

1. Linux fundamentals
2. Users and permissions
3. Processes and services
4. Networking
5. Troubleshooting
6. Monitoring
7. FinOps-oriented analysis
